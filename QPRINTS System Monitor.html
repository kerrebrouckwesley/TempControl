QPRINTS // System Monitor

Een rond scherm naast je pc dat live je CPU-temperatuur, GPU-temperatuur en FPS toont. De pc stuurt de waarden elke seconde via de USB-C-kabel door.

Tot en met 50 °C: blauw Boven 50 °C: rood

Installeren duurt ongeveer 15 minuten. Daarna start alles vanzelf telkens als je je aanmeldt.

QPRINTS //
SYSTEM MONITOR
CPU42°C
GPU48°C
FPS165

Wat je nodig hebt

Het scherm

Waveshare ESP32-S3-Touch-LCD-1.46 (rond, 412 × 412 pixels).

Een USB-C-datakabel

Let op: sommige kabels kunnen alleen opladen. Gebruik een kabel die ook data doorgeeft.

Een Windows-pc

Windows 10 of 11, 64-bit, met beheerdersrechten. Getest voor AMD Ryzen- en NVIDIA RTX-hardware.

Installeren

In vier stappen klaar

  1. Eenmalig · op een pc met VS Code

    Zet de software op het scherm

    Het scherm heeft eigen software (firmware) nodig. Die zet je er één keer op.

    1. Installeer Visual Studio Code. Open het, klik links op Extensions, zoek PlatformIO IDE en klik op Install.
    2. Kies File → Open Folder en open de map firmware uit het project.
    3. Sluit het scherm met de USB-C-kabel aan op de pc.
    4. Klik in de blauwe balk onderaan op het pijltje → Upload. De eerste keer downloadt PlatformIO een paar minuten lang de nodige onderdelen.
    5. Klaar zodra er SUCCESS staat. Op het scherm verschijnt WACHTEN OP PC.
    Upload mislukt of de poort wordt niet gevonden? Hou de BOOT-knop op het bord ingedrukt, druk kort op RESET, laat BOOT los en klik opnieuw op Upload.
  2. Alleen als je nog geen setup-bestand hebt

    Maak het setup-bestand

    Heb je TempMonitor-Setup-1.0.0.exe al gekregen? Sla deze stap dan over. Anders maak je het zelf. Je hebt daarvoor de .NET 10 SDK en Inno Setup 6 nodig.

    winget install JRSoftware.InnoSetup
cd pc-app
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1 -OutputDir E:\

    Vervang E:\ door je USB-stick, of laat -OutputDir weg om het bestand in de map dist te zetten.

    Werk-pc of beheerde laptop? Microsoft Defender for Endpoint blokkeert daar vaak zelfgebouwde setup-bestanden. Verkenner kan dan zelfs vastlopen. Schrijf het bestand dan rechtstreeks naar een USB-stick en voer het uit op je eigen gaming-pc.
  3. Op de gaming-pc

    Voer de setup uit

    1. Dubbelklik op TempMonitor-Setup-1.0.0.exe.
    2. Verschijnt Windows heeft uw pc beschermd? Klik op Meer informatie en daarna op Toch uitvoeren. Die melding komt omdat het bestand niet digitaal ondertekend is.
    3. Klik op Ja als Windows om beheerdersrechten vraagt.
    4. Laat het vinkje PawnIO-driver installeren aan staan. Zonder die driver kan Windows de CPU-temperatuur niet uitlezen.
    5. Klik op Installeren en daarna op Voltooien.

    De app draait onzichtbaar op de achtergrond. Je ziet dus geen venster of icoon, en dat is normaal.

  4. Controle

    Kijk of het werkt

    Sluit het scherm aan op de gaming-pc. Binnen een paar seconden verandert WACHTEN OP PC in SYSTEM MONITOR en verschijnen de temperaturen. Start een game om de FPS te zien.

    Komen er geen waarden? Kijk dan bij Problemen oplossen.

Dagelijks gebruik

Wat het scherm je vertelt

Je hoeft niets te doen. Na het aanmelden in Windows start de app vanzelf en zoekt het scherm op. Je kunt het scherm ook later aansluiten of even loskoppelen; de verbinding herstelt zich.

Blauw

CPU en GPU zitten allebei op 50 °C of lager. Normaal bij rustig gebruik.

Rood

Minstens één van de twee zit boven 50 °C. De ring kleurt rood, net als het getal dat te warm is. Tijdens het gamen is dat gewoon.

FPS

Het aantal beelden per seconde van het venster dat vooraan staat, dus van je game. Op het bureaublad staat er --.

Wachten op pc

Het scherm krijgt geen gegevens. VERBINDING VERLOREN betekent dat er eerder wel gegevens kwamen, maar al 3 seconden niet meer.

Hulp

Problemen oplossen

Begin altijd met het logbestand C:\ProgramData\TempMonitor\TempMonitor.log. Daarin staat of het scherm gevonden is en welke sensoren ontbreken.

Het scherm blijft op "WACHTEN OP PC" staan
  • Probeer een andere USB-C-kabel. Een kabel die alleen oplaadt, laat het scherm wel oplichten maar geeft geen gegevens door.
  • Kijk in Taakbeheer → Details of TempMonitor.exe draait. Zo niet, start de taak in Taakplanner of meld je opnieuw aan.
  • Sluit programma's die de USB-poort van het scherm bezet houden, zoals de seriële monitor in VS Code of de Arduino IDE.
  • Staat in het log Scherm niet gevonden? Koppel het scherm los en sluit het opnieuw aan.
De CPU-temperatuur blijft op "--" staan

De PawnIO-driver ontbreekt waarschijnlijk. Installeer hem in een terminal als administrator en herstart de pc:

winget install namazso.PawnIO
FPS staat op "--" terwijl ik een game speel
  • De FPS-meting volgt het venster dat vooraan staat. Klik eenmaal in je game zodat die de focus heeft.
  • Staat in het log PresentMon.exe niet gevonden of PresentMon kon niet starten? Installeer de setup dan opnieuw.
De setup start niet of Verkenner loopt vast

Dat gebeurt op beheerde pc's met Microsoft Defender for Endpoint. Daar blokkeert een beveiligingsregel nieuwe programma's die niet ondertekend zijn. De setup is in orde, maar mag op die pc niet draaien. Gebruik de setup op je eigen pc, of vraag je IT-beheerder om een uitzondering.

Het beeld staat ondersteboven of scheef

Pas in firmware/src/main.cpp de instelling ROTATION aan (0, 1, 2 of 3) en upload de firmware opnieuw, zoals in stap 1.

Aanpassen

Instellingen in de firmware

Deze waarden staan bovenaan firmware/src/main.cpp. Na een wijziging upload je de firmware opnieuw, zoals in stap 1.

InstellingStandaardWat het doet
HOT_THRESHOLD50.0Boven deze temperatuur kleurt het scherm rood.
BRAND"QPRINTS"De naam bovenaan het scherm.
ROTATION0Draait het beeld telkens een kwartslag (0–3).
DATA_TIMEOUT_MS3000Na hoeveel milliseconden zonder gegevens het scherm "verbinding verloren" toont.
Temperaturen via LibreHardwareMonitor, FPS via Intel PresentMon. Het scherm ontvangt elke seconde een regel als CPU=42.5;GPU=48.0;FPS=165 over USB (115200 baud).
